# Fastly icon

`fastly-icon.svg` is copied from the Fastly Agent Toolkit's packaged icon.
Its stopwatch path and red color match [Fastly's official SVG favicon](https://www.fastly.com/favicons/favicon.svg), verified in a browser on September 30, 2026.
The packaged version adds a title, explicit 256 by 256 dimensions, and a white background.
